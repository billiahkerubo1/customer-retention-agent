# Customer Retention Agent

## Overview

An AI-powered customer retention system combining
classical machine learning and agentic AI.

## Objectives

- Predict customer churn.
- Explain customer churn risk.
- Investigate customer histories.
- Recommend personalized retention strategies.
- Integrate approved retention actions.
- Monitor model and business performance.

## Technology Stack

- Python
- Pandas
- Scikit-learn
- XGBoost
- FastAPI
- LangGraph
- PostgreSQL
- Docker
